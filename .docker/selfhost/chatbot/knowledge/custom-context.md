# Context riêng của Team

> **Hướng dẫn**: Chỉnh sửa file này để thêm thông tin riêng của team bạn.
> Chatbot sẽ dùng nội dung này để trả lời câu hỏi liên quan.
>
> Đặt tên file theo format: `team-{teamId}-{mô tả}.md`
> Ví dụ: `team-dev-workflow.md`, `team-marketing-templates.md`

## Quy trình làm việc

### Daily workflow
- Mở AFFiNE → check Kanban board → xem task hôm nay
- Tạo page mới cho mỗi meeting notes
- Cuối ngày: update trạng thái task trên Kanban

### Weekly review
- Review tất cả task trong Database view
- Archive task đã hoàn thành
- Lên plan cho tuần sau trên Whiteboard

## Templates nội bộ

### Meeting Notes
- Tiêu đề: [Ngày] - [Tên cuộc họp]
- Người tham dự
- Nội dung thảo luận
- Action items (dùng todo checkbox)
- Deadline

### Project Brief
- Tên dự án
- Mục tiêu
- Timeline
- Resources
- Risks

## Quy ước đặt tên

- Page: `[Loại] - [Tên] - [Ngày]`
- Workspace: Theo tên team/dự án
- Tags: Dùng tiền tố (`proj-`, `team-`, `meeting-`)
